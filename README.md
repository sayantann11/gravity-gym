# Gravity Unisex Gym static website

Plain HTML, CSS and JavaScript. No Node.js, build step or backend is required.

## Publish on Render

1. Push these files to GitHub.
2. In Render, select **New → Static Site** and connect the repository.
3. Leave **Build Command** empty and set **Publish Directory** to `.`.
4. Add your custom domain, then replace `https://www.gravitygym.in/` in `index.html`, `sitemap.xml` and `robots.txt` with it.

The contact form opens WhatsApp and does not collect or store data. Confirm the address, prices, hours and sample coach/review content before publishing.
